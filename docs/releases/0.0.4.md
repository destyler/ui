# UI 0.0.4: Vue Once listener cancellation

## Scope

The four public packages (`@destyler-ui/react`, `@destyler-ui/solid`,
`@destyler-ui/svelte`, and `@destyler-ui/vue`) receive synchronized version 0.0.4.
Core dependencies remain `^0.3.4`. React, Solid and Svelte receive the version
bump only. The private workspaces are not published.

## Vue native Once cancellation

Steps click controls and Select Trigger, Content, Item, ClearTrigger and Label
now compose ordinary native Once consumers before core handlers. For example,
`@click.once.prevent` can veto the first action where the core handler checks
`event.defaultPrevented`; subsequent actions continue normally. Capture and
passive listener semantics remain unchanged, and passive listeners cannot veto.

## Custom components and Once lifetime

The new exported `useNativeEventProps` helper explicitly adapts a custom
DOM-forwarding component at its actual native receiving element. See the
[complete button example and lifecycle guide](../vue-once-listeners.md).
Arbitrary custom components, declared or undeclared emits, and callback props
retain their Vue semantics. Unadapted wrappers cannot guarantee first-event
cancellation before core.

Create one helper in setup per receiving element and use it every render.
Replacing a consumed callback does not rearm it. Removing the listener for a
completed render and then readding it, or replacing the receiving DOM node,
starts a fresh native Once lifetime. Preserve callback references when merging
listeners. The guide documents propagation, error and synthetic-event limits.

## Upgrade and verification

Upgrade the chosen framework package to 0.0.4. Existing native consumers need
no new API; custom DOM wrappers that need a Once veto should use the adapter.
This release does not undo the core accessibility migrations from
[UI 0.0.3](0.0.3.md).

PR #171's implementation passed 706 Vue unit tests, 170 SSR tests, typechecking,
build and lint. CI on Node 22 and 24 passed the four trusted Chromium click and
keydown cases for native and adapted receivers, alongside the full test suite.
The release pipeline rechecks the final tagged source before npm publication.

The generator proof uses an isolated scripts-disabled installation of
`changelogithub@15.0.5`. Run
`CHANGELOGITHUB_TEST_ROOT=/path/to/isolated/install node --test scripts/test-release-notes.mjs`
to verify automatic config discovery, versioned links, and absence of obsolete
0.0.3 breaking notices without network access during rendering. The release
workflow itself retains its existing `npx changelogithub` command.
