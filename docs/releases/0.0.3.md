# UI 0.0.3

## Scope

This release synchronizes the root and all four public `@destyler-ui/*`
packages at 0.0.3 and updates every `@destyler/*` catalog range to `^0.3.4`.
All frameworks consume the new core, not just Vue. Node >=22.22.3 and public
framework peer ranges are unchanged. Historical 0.0.2 notes remain historical.

Core 0.3.4 includes the breaking changes below. A patch version does **not**
mean that no migration is required. See the published
[core 0.3.4 release](https://github.com/destyler/destyler/releases/tag/v0.3.4).

## Breaking core migrations

### Steps keyboard navigation and completion roles

Steps now uses one roving tab stop instead of placing every non-linear trigger
in the Tab sequence. Arrow keys, Home and End move focus without selecting a
step. Enter and Space activate the native trigger button. Review keyboard-order
assertions and custom key handlers. Render one native, enabled, mounted trigger
for every index from zero through `count - 1`; per-trigger native disabling and
partially mounted lists are not supported navigation modes. Review linear,
controlled and RTL behavior.

The completion summary is no longer a `tabpanel` labelled by a nonexistent
trigger. Update role queries and give the summary meaningful content or a
heading. If advancing hides the focused element, move focus appropriately.
See the [core Steps keyboard migration](https://github.com/destyler/destyler/blob/16e22b9336e18b6026aa7f0049a2470ffe65392b/packages/components/steps/docs/steps.mdx#keyboard-navigation).

### Select focus ownership

In default composite mode, focus belongs to Content, which owns the listbox
role and active-descendant relationship; its nested List no longer has a tab
stop. Move List-specific focus styling and imperative focus assumptions to
Content, or review explicit custom focus overrides. Non-composite mode retains
the List tab stop. See the [core Select focus migration](https://github.com/destyler/destyler/blob/16e22b9336e18b6026aa7f0049a2470ffe65392b/packages/components/select/docs/select.mdx#focus-ownership).

## Vue listener and callback fixes

Steps and Select now run ordinary caller listeners before core handlers,
including `asChild`, while preserving listener arrays and deduplication.
Steps Root forwards change callbacks through its Vue emits contract. Listener
replacement, refs, attributes, and existing controlled behavior are covered by
the focused regressions.

Ordinary caller cancellation can prevent core behavior only when the core
handler checks `event.defaultPrevented`. This is not a new universal veto
contract: focus and pointer handlers that do not check it retain their existing
behavior. Wrapper `.once.prevent` may run after core and therefore cannot be
relied on to cancel that core action. Capture and passive semantics are
unchanged. Review cancellation-sensitive compositions explicitly.

## Upgrade

Explicitly install `@destyler-ui/*@0.0.3` (or `^0.0.3`) for each framework in use
and refresh the application lockfile. The range `^0.0.2` excludes `0.0.3`.
Keep multiple UI framework packages synchronized. Core's `^0.3.3` range already
permits 0.3.4 on a fresh resolution; an existing frozen lockfile does not update
itself. Test keyboard navigation, focus styles, completion role queries,
controlled callbacks, SSR/hydration, and cancellation-sensitive listeners in
your application after upgrading.

## Validation and limits

The Vue patch adds 320 Happy DOM unit regressions. Earlier PR #169 CI passed
7,578 tests with 48 skipped per Node matrix entry, including the existing
Chromium Steps (27) and Select (46) cases. Those results belong to the earlier
wrapper candidate, not the final UI 0.0.3/core 0.3.4 integration.

Before release, the final commit must pass the normal CI, packed-consumer,
exact-core compatibility, documentation, and browser checks with real core
0.3.4 registry artifacts. The exact-core gate is now pinned to 0.3.4. Neither
Happy DOM results nor the bounded existing browser cases establish exhaustive
browser or assistive-technology coverage. No new broad accessibility guarantee
is made.
